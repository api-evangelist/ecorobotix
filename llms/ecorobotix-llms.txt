# Ecorobotix

> Swiss agricultural technology company (founded 2011, Yverdon-les-Bains, Switzerland) building AI-driven ultra-high-precision crop-care equipment. The ARA smart sprayer pairs Plant-by-Plant AI detection with UHP-Spray-Technology to classify crops versus weeds in under 250 milliseconds and treat individual plants, cutting plant-protection input volumes by up to 95% versus broadcast spraying. Over 1,000 units deployed worldwide.

## API surface

Ecorobotix runs no public developer program. There is no developer portal, no published API reference, no API signup and no SDK. One real API exists and it is customer-only:

- [Ecorobotix Portal](https://portal.ecorobotix.cloud/): the customer cloud portal for ARA fleet, treatment and field data. Django REST Framework application.
- Portal API base: `https://portal.ecorobotix.cloud/api/` — every path 302-redirects anonymous clients to `/auth/login/`.
- OpenAPI schema: `https://portal.ecorobotix.cloud/api/schema/` — a real drf-spectacular endpoint that returns HTTP 401 `{"detail": "Authentication credentials were not provided."}` to anonymous clients. The specification exists; it is not public.
- Swagger UI: `https://portal.ecorobotix.cloud/api/schema/swagger-ui/` — deployed, HTTP 401, same gate.
- `https://api.ecorobotix.cloud/` — a separate AWS API Gateway host behind CloudFront that returns HTTP 503 `{"message":"Service Unavailable"}` on every path probed.

An agent cannot integrate with Ecorobotix without a customer account. Do not attempt to reconstruct the schema; request access through the contact form below.
